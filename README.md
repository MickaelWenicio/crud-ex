# Como rodar o projeto localmente

## Clonar o repositório

```bash
git clone https://github.com/MickaelWenicio/crud-ex.git
```

## Acessar a pasta do projeto

```bash
cd crud-ex
```

---

# Próximos passos

Após clonar o projeto:

* Acesse a pasta **`/front`** para instruções específicas do frontend.
* Acesse a pasta **`/back`** para instruções específicas do backend.

Cada uma dessas pastas possui um **README próprio**, contendo:

* Requisitos
* Configuração de variáveis de ambiente
* Instalação de dependências
* Como executar o projeto
* Informações específicas da stack utilizada

---

# Observações

* Frontend e backend são independentes, mas funcionam de forma integrada.
* Certifique-se de configurar corretamente as variáveis de ambiente antes de executar.
* Consulte sempre os READMEs específicos para detalhes técnicos.
